# 金融ニュース便（毎朝）

Kelly が「お金のことを一から学ぶ」ための、毎朝の3分ニュース。
むずかしい言葉は必ず言い換える。ニュースを読むのが目的ではなく、**自分のお金と仕事につなげて考えられるようになる**のが目的。

## 届く形

毎朝、以下の5ブロックで届く。全部読んで3分。

| ブロック | 中身 | ねらい |
|---------|------|--------|
| ① 3行まとめ | 今日いちばん大事なことを3行 | 忙しい日はここだけ |
| ② 今日の数字 | 日経平均・ドル円・金利など | 数字に慣れる |
| ③ 今日のニュース（3本） | 「何が起きた → なぜ大事 → Kelly にどう関係する」 | 自分ごとにする |
| ④ 今日の一語 | 用語をひとつだけ、たとえ話で | 語彙を貯める |
| ⑤ ひとこと | 今日の小さな行動・気づき | 動きに変える |

## 情報源のルール

- **情報源の言語は問わない。** 英語・中国語・その他、どの言語のメディアから拾ってもよい
- **ただし出力は必ず日本語。** 原文の引用も、必要なら日本語訳を添える
- 日本語メディアだけだと、海外の動きが半日〜1日遅れて入ってくる。**英語・中国語の一次情報を優先的に混ぜる**
- 毎回いちばん下に「今日の情報源」表を付け、**どの言語のどのメディアから拾ったか**を明示する
- 各ニュースの出典リンクにも `（英語）` `（中国語）` と言語を書く。Kelly が自分で原文を見に行けるように

**よく使う情報源の例**

| 言語 | メディア |
|:----:|---------|
| 英語 | Reuters, Bloomberg, Saxo Market Quick Take, CNBC, Japan Times, Kiplinger |
| 中国語 | 中金在线, 新華社, 中国人民銀行（人民元 基準値）, 汇通财经 |
| 日本語 | 日本経済新聞, 株探, 外為どっとコム, 総務省統計局, 日本銀行 |

## 書き方のルール

- **専門用語は禁止。使うときは必ずカッコで言い換える**（例：「利上げ（＝お金を借りるときの利息が上がること）」）
- ニュースは3本まで。多いと読まなくなる
- 1本ごとに必ず「Kelly にどう関係する？」を書く。ライフコンサルタント／UBM（海外積立・オフショア・プライベートバンク）の仕事と、Kelly 自身の家計の両面から
- 相場の予想はしない。「上がる／下がる」ではなく「何が起きて、どう考えるか」
- 出典リンクを必ず載せる。あとで自分で確かめられるように
- 覚えた言葉は `用語ノート` に自動で追加していく

## ファイル

- 日次: `finance/news/YYYY-MM-DD.md`
- 用語集: `finance/news/用語ノート.md`

## 学びの段階（ゆるやかに）

| 時期 | テーマ |
|------|--------|
| 1〜2週目 | 数字に慣れる（日経平均・ドル円・金利ってなに？） |
| 3〜4週目 | 物価と金利の関係、円安・円高が生活に効く仕組み |
| 2ヶ月目 | 投資のいれもの（NISA・iDeCo）と、海外積立との違い |
| 3ヶ月目〜 | 顧客に説明できるレベルへ。ニュースから提案トークを作る |
